# Anki Quiz Bank (輕量級題庫測驗與錯題本系統)

一個基於 **Vite + React + Tailwind CSS** 構建的現代化、輕量級單機版題庫測驗系統。支援離線作答、PWA 行動裝置安裝、錯題自動收集、以及基於 Anki (SM-2) 啟發的加權隨機複習演算法。

---

## 🌟 特色功能

1. **Anki 加權隨機演算法**：
   - 系統依據您的答題歷史自動調整題目權重。
   - **答錯的題目會被自動加權**，更頻繁地出現在測驗中；**答對且連勝的熟練題目則會被降權**，將精力集中在最不熟悉的弱點。
2. **自動錯題本**：
   - 作答錯誤的題目會自動記錄，使用者隨時可以進入「錯題本」進行複習或單獨進行「錯題抽測」。
3. **分類刷題練習**：
   - 系統會自動解析題目編號（例如 `[EB010001]` ➔ `EB01` 分類），自動將題目分組，便於按章節有計劃地練習。
4. **隨身 PWA 應用程式**：
   - 支援「新增至主畫面」安裝。在 iOS (Safari) 或 Android (Chrome) 上將其加到案頭後，可像原生 App 一樣以流暢的全螢幕模式開啟。
5. **雲端備份與同步**：
   - 支援使用 GitHub Gist 作為個人雲端資料庫，進行跨裝置、跨瀏覽器的進度自動同步。
6. **優化鍵盤與手勢操作**：
   - **電腦版快捷鍵**：`A`, `S`, `D`, `F`, `G` 選擇選項，`Space` / `Enter` 送出或下一題，`Esc` 略過。
   - **自動跳題**：答對時會自動在 0.8 秒後進到下一題，大幅提升刷題流暢度。

## 🛠️ 本地開發與執行

### 1. 安裝相依套件
```bash
npm install
```

### 2. 啟動本機開發伺服器

npm run dev

## 🚀 一般使用者如何使用？（免安裝）

如果您只是想使用這個題庫系統，不需要懂任何程式碼，只要直接下載本專案目錄下的 **`題庫離線版.html`** 檔案到您的電腦或手機。

雙擊打開這個檔案，它就會在瀏覽器中自動全螢幕執行，**完全不需要網路**也能順暢運作！您可以隨時匯入自己的 JSON 題庫檔進行練習。

## 📝 題庫 JSON 資料格式

本系統接受一個 JSON 陣列作為題庫來源。每個題目物件格式如下：

```json
[
  {
    "title": "[EB010001] 題目文字敘述",
    "options": [
      { "label": "A", "text": "第一個選項說明" },
      { "label": "B", "text": "第二個選項說明" },
      { "label": "C", "text": "第三個選項說明" },
      { "label": "D", "text": "第四個選項說明" }
    ],
    "answer": "A",
    "explanation": "（選填）本題解析或說明文字",
    "imageUrl": "（選填）題目附圖網址或 Base64 字串"
  }
]
```

* **分類說明**：題目 `title` 開頭若帶有 `[分類名稱]` 標籤（如 `[EB01]`），系統會自動識別並將其分類至對應的「分類練習」分組中。

## ☁️ 雲端同步教學 (GitHub Gist)

本系統支援透過 GitHub Gist 將「自訂題庫」與「答題統計紀錄」跨裝置同步，資料完全儲存在您自己的 GitHub 帳號中，安全且保有隱私。

### 第一步：取得 GitHub Token
1. 登入 GitHub 後，前往 `Settings` -> `Developer settings` -> `Personal access tokens (Tokens (classic))`。
2. 點擊 `Generate new token (classic)`。
3. Expiration（期限）建議選 `No expiration`（無期限）。
4. 在 Select scopes 清單中，**僅需勾選 `gist`**。
5. 點擊 Generate token，並複製產生的 `ghp_...` 亂碼字串（這就是你的 Token）。

### 第二步：首次在網頁上綁定（上傳資料）
1. 在題庫網頁點擊右上角進入「設定」。
2. 貼上剛剛的 Token（建議勾選「記住 Token」）。
3. **⚠️ 留空「指定 Gist ID」欄位**。
4. 點擊「手動上傳備份」。成功後，Gist ID 欄位會自動產生一串亂碼，這就是您的**專屬雲端存檔 ID**（建議妥善保存）。

### 第三步：在其他裝置還原（下載資料）
1. 於另一台裝置打開題庫網頁「設定」。
2. 貼上您的 Token，並在「指定 Gist ID」填入剛剛產生的**雲端存檔 ID**。
3. 點擊「手動下載同步」，完成後重新整理網頁，進度即全部恢復！

## 🤖 如何將現有題庫 (PDF/Word) 轉換為 JSON 格式

如果您手邊有現成的 PDF、Docx 等格式的題庫，可以直接將檔案上傳給常用的 AI 工具（如 ChatGPT、Claude），並附上以下的 Prompt，讓 AI 幫您自動轉換成可以匯入本系統的 JSON 格式！

### AI 轉換 Prompt 範本
請複製以下內容並連同題庫檔案發送給 AI：

```text
你好！我有一份題庫檔案（如附件），請幫我將這份檔案中的所有選擇題，轉換成特定的 JSON 格式。

【轉換規則與要求】
1. 請以嚴格的 JSON 陣列 (Array) 格式輸出，不要省略任何括號。
2. 題目文字與分類：請在 title 欄位的最前方加上分類標籤（如 [EB01] 或 [第一章]），這會幫助系統自動分組。
3. 每個選項必須包含 label (如 A, B, C, D) 和 text (選項內容)。
4. 如果有多選題，answer 欄位請輸出包含正確選項 label 的陣列，例如 ["A", "C", "D"]。
5. **關於詳解 (explanation)**：請務必在解析中直接「引用選項的文字內容」，**絕對不要**使用 A、B、C、D 這類代號來指稱選項（例如：請寫「選項『蘋果』是錯的」，不要寫「選項 A 是錯的」）。因為系統會自動「隨機打亂選項順序」，使用代號會導致使用者看解析時完全對不上。
6. 請確保 JSON 格式完全正確，特別是引號、換行符號的跳脫處理。

【JSON 資料結構範例】
[
  {
    "title": "[分類01] 以下哪個選項是正確的？",
    "options": [
      { "label": "A", "text": "選項 A 的內容" },
      { "label": "B", "text": "選項 B 的內容" },
      { "label": "C", "text": "選項 C 的內容" },
      { "label": "D", "text": "選項 D 的內容" }
    ],
    "answer": "A",
    "explanation": "（如果有解析請填寫在這，若無則留空字串）"
  }
]

請開始解析我提供的題庫，並直接輸出轉換後的 JSON 陣列。若檔案過大，可以分批輸出（如每次 50 題）。
```
